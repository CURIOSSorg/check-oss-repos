# Check OSS Repos

This repository has some basic templates for auditing open source repositories.

- [audit-template.md](./audit-template.md): This file was used originally by a consultant ([@RichardLitt](https://github.com/RichardLitt)) to review repositories for open source health. It is detailed and aimed at helping maintainers.
- [simple-audit-template.md](./simple-audit-template.md): This file is a simplified version meant for newcomers to a project to judge its health. Start here!

## Contribute

Please make any PRs or open issues if anything is confusing or could be improved!
