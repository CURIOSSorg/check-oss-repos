# Check OSS Repos

This repository has some basic templates for auditing templates.

- [audit-tempate.md](./audit-template.md): This file was used originally by a consultant ([@RichardLitt](https://github.com/RichardLitt)) to review repositories for open source helath. It is detailed and aimed at helping maintainers.
- [simple-audit-template.md](./simple-audit-template.md): This file is a simplified version meant for newcomers to a project to judge it's health. Start here!
